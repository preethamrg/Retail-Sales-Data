# Retail Sales Data Analysis

## Objective
Perform an end-to-end analysis of retail order data focusing on data quality validation,
pricing consistency, revenue accuracy, and business insights.

## Dataset
Transaction-level retail sales data containing pricing, discounts, sales channels,
customer attributes, and ratings.

## Project Structure
- data/raw : raw input dataset
- notebooks : analysis notebooks
- src : reusable Python utility functions

## Analysis Plan
1. Data Quality & Validation
2. Aggregations & KPIs
3. Advanced Groupby Analysis
4. Visualization & Business Insights

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn
